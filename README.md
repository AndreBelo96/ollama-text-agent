# Mini AI Text Modifier

Desktop app to correct and translate .txt files using a local LLM via Ollama.

## Requirements
- Python 3.x
- [Ollama](https://ollama.com) installed and running with the qwen2.5:14b model

## Installation
pip install requests

## Usage
python main.py

## Features
- Grammar and punctuation correction
- Multi translation
- Output saved as a separate file (_corrected.txt / _translated.txt)
