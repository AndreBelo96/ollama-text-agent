# AI Projects

A collection of AI-powered tools built with local LLMs via Ollama.

---

## 1. AI Text Agent

A desktop tool to correct and translate text files using a local LLM.
The agent autonomously decides which operation to perform based on the user's natural language request (tool calling).

**Stack:** Python, Tkinter, Ollama, qwen2.5:14b

**How it works:**
1. User loads a .txt file
2. User describes what they want in natural language
3. The LLM decides autonomously whether to correct or translate (tool calling)
4. Result is saved to a new file

**Run:**
```bash
python text-agent/main.py
```

## 2. DnD Campaign Generator

A multi-agent AI pipeline that generates complete D&D campaigns with narrative text and images.

**Stack:** Python, Ollama, qwen2.5:14b, Hugging Face (FLUX.1)

**How it works:**

| Agent | Role | Runs on |
|---|---|---|
| Agent 1 | Generates campaign structure (JSON) | Ollama local |
| Agent 2 | Converts descriptions to image prompts | Ollama local |
| Agent 3 | Generates images from prompts | Hugging Face API |
| Agent 4 | Writes full narrative from campaign data | Ollama local |

**Output:**
- `campaign.txt` — full narrative for the DM and players
- `prompts.md` — technical image prompts generated by Agent 2
- `villain.png`, `scene_1-3.png`, `npc_1-2.png` — generated images

**Requirements:**
- [Ollama](https://ollama.com) running with `qwen2.5:14b`
- Hugging Face account with API token

**Setup:**
```bash
pip install requests python-dotenv huggingface_hub pillow
```

Create a `.env` file:

HF_TOKEN=your_token_here

**Run:**
```bash
python dnd-generator/main.py
```
